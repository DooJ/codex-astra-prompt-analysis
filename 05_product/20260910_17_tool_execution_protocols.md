# 17. 도구 호출·검색·이미지의 실행 규약

분류: 실행 도구에 특화된 인터페이스 안내 · 기준: 2026-09-10 공개 판본

이 문서는 공개 자료의 해설이며, 현재 환경에 실행 지침으로 설치된 문서가 아닙니다.

## 어떤 상황을 다루는가

모델이 도구를 어떤 형식으로 호출하고, 비동기 결과를 어떻게 기다리고, 반환된 텍스트·이미지·오디오를 어떻게 사용자에게 전달하는지 설명한다.

## 코드 모드 규칙

- 실제 제공된 도구 목록과 호출 형식을 확인한다.
- 도구 설명에 생략된 지연 로딩 기능은 도구 메타데이터에서 찾아 사용할 수 있다.
- JavaScript로 도구 호출을 묶되 실행 환경에서 지원하는 기능만 사용한다.
- 독립된 호출은 병렬로 묶을 수 있지만 필요한 Promise는 끝까지 기다린다.
- 실행이 종료되면 기다리지 않은 작업이 버려질 수 있는 수명 규칙을 고려한다.
- 텍스트, 이미지, 오디오와 생성 미디어는 지정된 결과 전달 함수를 사용한다.
- 작업 진행 중 상태와 종료 결과를 구분하고, 대기 도구는 실행 도구가 돌려준 식별자에 맞춰 호출한다.

## 웹·이미지 규칙

웹 도구 설명에는 검색, 페이지 열기, 링크 이동, 문서 내 검색과 일부 전문 조회 기능이 있다. 변동 가능한 사실, 명시적 검색 요청, 정확한 출처가 필요한 경우 등의 검색 기준과 출처 표시·인용 제한이 함께 들어 있다.

이미지 도구 설명은 새 이미지 생성과 기존 이미지 편집을 구분한다. 편집 대상의 파일 경로나 대화의 이미지 참조를 정확히 지정하고 실제 결과를 표시하도록 한다.

## 처리 흐름

1. 필요한 기능이 실제로 제공되는지 확인한다.
2. 정확한 입력 형식과 대상 식별자를 준비한다.
3. 도구를 호출하고 필요하면 결과를 기다린다.
4. 반환된 값·오류·상태를 확인한다.
5. 사용자에게 적합한 형식으로 결과를 표시한다.

## 예외와 경계

프롬프트 안에 도구 이름과 예제가 있다고 해서 그 도구가 생성되는 것은 아니다. 실제 실행기가 같은 인터페이스를 제공해야 한다.

원문에는 같은 도구의 여러 서명이나 설명 조각이 수록돼 있다. 예제를 그대로 복사하기 전에 현재 도구의 스키마를 확인해야 한다.

## 이해를 위한 사례

이미지 도구가 성공했다고 말한 텍스트만 표시하는 것과 반환된 실제 이미지를 표시하는 것은 다르다. 필요한 출력 형식까지 맞춰야 사용자가 결과를 확인할 수 있다. 설명용 사례다.

## 재사용 관점

도구를 발견하고 정확히 호출하고 결과를 확인하는 절차는 공통화할 수 있다. 함수 이름, 실행 수명, 미디어 표현 규약은 환경별 어댑터에 해당한다.
