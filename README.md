주제별 문서는 다음 디렉터리에 있습니다.

- `01_principles`: 역할, 자율성, 소통, 실행과 검증
- `02_execution`: 실행 모드, 지속 작업, 협업, 스킬과 플러그인
- `03_permissions`: 샌드박스, 승인, 위험 심사, UI 조작
- `04_memory`: 기억 조회, 경험 추출, 통합, 문맥 전환
- `05_product`: 도구, 데스크톱 자동화, 코드 리뷰, 실시간 대화
