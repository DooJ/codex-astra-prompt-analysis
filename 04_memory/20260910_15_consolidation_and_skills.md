# 15. 기억 통합과 스킬화

분류: 기억 작성 2단계 · 기준: 2026-09-10 공개 판본

이 문서는 공개 자료의 해설이며, 현재 환경에 실행 지침으로 설치된 문서가 아닙니다.

## 어떤 상황을 다루는가

여러 작업에서 나온 기억 후보를 정리해, 다음 수행자가 검색하고 실제 절차로 사용할 수 있는 지식 체계를 만드는 과정이다.

## 결과물의 역할

| 결과물 | 담는 내용 |
|---|---|
| MEMORY.md | 업무별 선호, 검증된 지식, 실패와 해결법, 근거 연결 |
| memory_summary.md | 사용자·업무의 압축 정보와 검색 안내 |
| rollout_summaries/ | 개별 실행의 결과와 근거 |
| skills/ | 반복 수행할 수 있는 절차·스크립트·템플릿 |

요약 파일은 상세 내용을 모두 복제하는 두 번째 본문이 아니라 필요한 자료로 이동시키는 안내 역할을 한다.

## 두 가지 작업 방식

초기 구축은 입력 전체의 범위를 살펴보고 업무 묶음과 기본 구조를 만든다. 증분 갱신은 새로 추가·수정·삭제된 자료를 중심으로 기존 지식을 보완한다.

파일이 나열된 순서를 최신순이나 중요도순으로 가정하지 않는다. 시간 정보, 현재 변경과 실제 증거를 함께 확인한다.

## 처리 흐름

1. 기존 기억과 새 후보를 확인해 초기 구축인지 갱신인지 정한다.
2. 같은 업무에 속하는 경험을 모으고 사용자 선호를 정리한다.
3. 중복을 합치고 충돌·오래된 정보의 근거를 확인한다.
4. 반복 가능한 절차는 기존 스킬을 보완하거나 새 스킬로 분리한다.
5. 기억 본문에서 관련 스킬과 근거를 연결한다.
6. 전체 내용이 확정된 뒤 요약·색인을 갱신한다.
7. 연결된 파일, 중복, 오래된 근거와 검색 가능성을 점검한다.

## 스킬로 만들 때 들어가는 내용

- 언제 적용하고 언제 적용하지 않을지.
- 시작 전에 필요한 정보와 준비 사항.
- 구체적인 작업 단계.
- 도구 호출이나 탐색을 줄이는 방법과 중단 조건.
- 자주 발생하는 증상, 원인과 수정 방법.
- 완료를 확인할 검증 항목.
- 필요할 때만 추가하는 스크립트, 예시와 출력 템플릿.

## 삭제·정정·무변경 처리

근거 자료가 삭제됐다고 관련 기억을 모두 기계적으로 지우지 않는다. 다른 근거로 여전히 지지되는 부분은 남기고, 삭제된 자료에만 의존하는 부분을 제거하거나 낮은 확신으로 바꾼다.

새로운 가치가 없다면 재배열과 문구 변경을 불필요하게 반복하지 않는다. 원시 기록의 불변성과 가공된 기억의 갱신을 구분한다.

원문에 있는 v1 표식과 최근 세 개 기억 날짜의 색인 규칙은 해당 저장 형식의 요구사항이다.

## 이해를 위한 사례

여러 장애 조사에서 같은 진단 순서가 반복 검증됐다면 이를 하나의 장애 조사 스킬로 정리할 수 있다. 특정 실행에서만 유효했던 임시 경로나 미검증 우회법은 일반 절차와 구분한다. 설명용 사례다.

## 재사용 관점

사용자가 말한 “일을 하며 쌓인 노하우를 스킬로 정리한다”는 구조가 가장 직접적으로 나타나는 부분이다. 기억 후보에서 검증·통합·절차화를 거쳐 다음 작업에 제공된다.
